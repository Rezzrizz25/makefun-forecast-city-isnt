A make.fun entry for the **Funniest Forecast for a City That Isn't** bounty: write one line, at most 120 characters, the funniest weather forecast for a city that does not exist.

## The entry

> Spite Falls: clear skies, gentle breeze, and a 90% chance of rain falling sideways out of sheer spite.

(102 characters. The forecast opens in flat bulletin voice, then the weather itself misbehaves — the rain falls sideways out of sheer spite, and the invented city is even named for it.)

## Run

```sh
node main.ts
```

This writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with in-code gate checks: single line, non-blank, 1–120 characters, plus a read-back verification that the file on disk is byte-identical to the entry.
